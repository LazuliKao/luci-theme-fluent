# Translation guidance

You are translating luci-theme-fluent LuCI interface copy into Polish (`pl`).

Translation goals: keep the text concise, natural, and appropriate for a router/web UI while improving terminology accuracy, consistency, and professionalism.

## Core rules

1. Use concise, professional, natural technical UI Polish.
2. Prefer short labels and short sentences.
3. Keep terminology consistent across the entire file.
4. Preserve product names, project names, and technical names:
   - LuCI stays `LuCI`
   - Fluent stays `Fluent`
   - FluentUI stays `FluentUI`
   - View Transition API stays `View Transition API`
5. Keep all variables, placeholders, and format specifiers unchanged, including `%s`, `{count}`, and inline code.
